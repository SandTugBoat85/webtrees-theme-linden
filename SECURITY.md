# Security

## Supported versions

Only the latest release of Linden gets security fixes. The control panel tells you when a new
version is available.

## Reporting a problem

Please don't report security problems in a public issue. Use **Report a vulnerability** on this
repository's **Security** tab instead, which reaches the maintainer privately.

Please include the Linden and webtrees versions, what an attacker could do, and the steps to show
it. You should hear back within a week.

Problems in webtrees itself, rather than in this theme, belong with the webtrees project:
https://github.com/fisharebest/webtrees/security
